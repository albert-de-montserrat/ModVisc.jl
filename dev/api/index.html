API

ModVisc.AbstractGeometry — Type

Supertype for all supported pore inclusion geometries.

ModVisc.ElasticModel — Type
ElasticModel(matrix_bulk, matrix_shear, fluid_bulk, components...;
             matrix_density=1, density_contrast=0)

Material and pore geometry for the elastic model. Moduli must use consistent units. Densities are used only for wave speeds.

ModVisc.ElasticResult — Type

Effective elastic properties at one porosity.

ModVisc.Film — Type

Film-like oblate inclusions with aspect ratio aspect_ratio ≪ 1.

ModVisc.MeltFraction — Type

A geometry and its fraction of the total pore volume.

ModVisc.PoreFraction — Type

A geometry with isolated and hydraulically connected pore fractions.

ModVisc.SolverOptions — Type

Controls fixed-point convergence for the self-consistent solver.

ModVisc.Spheroid — Type

Oblate spheroidal inclusions with aspect ratio in (0, 1].

ModVisc.Tube — Type

Tubular inclusions with Mavko's cross-section parameter shape.

shape = 0 describes tapered tubes; increasing values approach a circular cross-section.

ModVisc.ViscosityResult — Type

Effective viscosities and convergence metadata for one porosity.

ModVisc.ViscousModel — Type
ViscousModel(matrix_shear, components...)

Self-consistent viscous model. matrix_shear is the intrinsic matrix shear viscosity and the MeltFraction component fractions must sum to one.

elasticity!(...)

ModVisc.poisson_ratio — Method

Return Poisson's ratio from isotropic bulk and shear moduli or viscosities.

ModVisc.spheroid_fit — Function
spheroid_fit(porosity, aspect_ratio, matrix_shear=1)

Equation 5 of Schmeling, Kruse & Richard (2012). Returns the fitted (bulk, shear) viscosities for spheroidal inclusions. Both are zero at and above the critical porosity.

ModVisc.spheroid_fit! — Function
spheroid_fit!(bulk, shear, porosities, aspect_ratio, matrix_shear=1)

Fill preallocated bulk and shear viscosity arrays using spheroid_fit. aspect_ratio and matrix_shear may be scalars or arrays with axes matching porosities.

ModVisc.viscosity — Function
viscosity(model, porosity[, options]) -> ViscosityResult

Solve the relaxed self-consistent equations for effective bulk and shear viscosity at one melt fraction. This is the viscous correspondence of equations A4 and A6 in Schmeling, Kruse & Richard (2012), with an incompressible matrix and zero pore-fluid viscosities.

ModVisc.viscosity_profile — Function
viscosity_profile(model, porosity_or_porosities[, options])

Calculate effective viscosities at one porosity or over an array of porosities. Scalar input returns a ViscosityResult; array input returns arrays in a named tuple.

ModVisc.viscosity_profile! — Function
viscosity_profile!(bulk, shear, poisson, model, porosities[, options])
viscosity!(bulk, shear, poisson, model, porosities[, options])

Fill preallocated result arrays for the supplied porosity values.
