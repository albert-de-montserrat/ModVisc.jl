ModVisc.jl

ModVisc.jl calculates effective elastic moduli, seismic velocities, and viscosities for partially molten materials using the self-consistent inclusion model of Schmeling, Kruse & Richard (2012).

Viscous example

using ModVisc

model = ViscousModel(1.0, MeltFraction(Tube(0.0), 1.0))
viscosity(model, 0.05)
ViscosityResult{Float64}(4.594970633364197, 0.805643634710402, 0.4171748156413209, 19, true)

viscosity_profile also dispatches on a scalar porosity and returns a ViscosityResult:

result = viscosity_profile(model, 0.05)
result.bulk
4.594970633364197

For several porosities, use the explicit profile API or collection dispatch:

porosities = 10.0 .^ range(-4, -1; length=20)
profile = viscosity_profile(model, porosities)
profile.bulk == viscosity(model, porosities).bulk
true

Elastic example

using ModVisc

model = ElasticModel(
    66e9,
    40e9,
    20e9,
    PoreFraction(Spheroid(0.1), 0.0, 1.0);
    matrix_density=3300.0,
    density_contrast=300.0,
)
elasticity(model, 0.01)
ElasticResult{Float64}(6.482651401217554e10, 3.85059453125542e10, 6.482199586599203e10, 3.813993605564326e10, 0.25209220700390045, 0.25404794862981256, 5935.856058614799, 3417.46772144254, 5923.259210818916, 3401.186970797919, (8, 9, 1), true)
profile = elasticity_profile(model, [0.001, 0.01, 0.1])
profile.relaxed_bulk == elasticity(model, [0.001, 0.01, 0.1]).relaxed_bulk
true
